# Prefab Intake

Create reusable Unity prefabs here after art/audio/data are imported.

- `Characters/`: player, NPC, enemy, boss prefab variants.
- `Nodes/`: battle, rest, shop, remnant interactable nodes.
- `UI/`: HUD widgets, panels, buttons, status rows.
- `Runtime/`: bootstrap/runtime helper prefabs.

Prototype-only generated objects may stay scene-built until the prefab contract is stable.
