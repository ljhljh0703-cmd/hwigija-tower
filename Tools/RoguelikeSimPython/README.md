# RoguelikeSimPython

Python analysis skeleton for seed replay CSVs generated by `Tools/RoguelikeSim`.

No external dependency is required for the default summary path. If `matplotlib` is installed locally, the script also writes a PNG chart; otherwise it writes an ASCII chart.

## Run

```bash
python3 Tools/RoguelikeSimPython/analyze_seed_replay.py \
  --input Tools/RoguelikeSim/output/seed_replay.csv \
  --output-dir Tools/RoguelikeSimPython/output
```

Outputs:

- `policy_summary.csv`
- `policy_summary.md`
- `floor_reached_histogram.txt`
- `floor_reached_histogram.png` when `matplotlib` is available

Analysis outputs are evidence for balance review only. They do not lock GDD decisions.
