# Implementation Ready Checklist

This checklist separates work that is already scaffolded from work that needs writer/design input.

## Already Scaffolded

- Unity project root is the repository root.
- Prototype scene is generated by `HwigiTower.EditorTools.PrototypeSceneBuilder.Build`.
- Placeholder data exists for:
  - 12 abilities
  - 4 synergies
  - 6 enemies
  - 2 bosses
  - 25 encounters
- Battle, rest, shop, and remnant nodes resolve through `PrototypeRunState`.
- Deterministic encounter and combat flow use seeded run context.
- Ability/synergy numeric hooks are wired for:
  - `player.attack_bonus`
  - `player.max_hp_bonus`
- Reflection/recall pipeline is wired through cached on-device/fake LLM provider.
- MLC native bridge is scaffolded and falls back when plugin is absent.
- Android build harness fails early when Android support is not installed.

## Replace When Design Is Ready

- Replace `SO_Ability_Placeholder_*` with approved ability names, tags, text, and numeric params.
- Replace `SO_Synergy_Placeholder_*` with approved synergy conditions/effects.
- Replace `SO_Enemy_Placeholder_*` and `SO_Boss_Placeholder_*` with approved combat specs.
- Replace `SO_Encounter_Placeholder_*` with approved encounter text and node distribution.
- Replace fake/fallback LLM output after D-005 model acceptance decision.
- Replace in-memory SQLite scaffold with native SQLite persistence after plugin approval.
