## Conversion Rules
- Do not parse Markdown at runtime.
- Convert each event into EncounterData/SO or existing baker source data.
- Keep internal instability effects hidden from player-facing UI.
- Use preview text for choice buttons and resultText for the result panel.
- Mataios content is intent only; final dialogue remains writer-owned.
