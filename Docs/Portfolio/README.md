# Portfolio

## 2D Concept to 8-Direction Game Asset Pipeline

- Case study HTML: [voxel-turnaround-case-study.html](voxel-turnaround-case-study.html)
- Tool README: [../../Tools/VoxelTurnaround/README.md](../../Tools/VoxelTurnaround/README.md)

The case study shows an AI-assisted game asset prepass:

```text
front/side concept image
  -> voxel turnaround prepass
  -> 8-direction reference PNGs + manifest.json
  -> PerfectPixel / sprite-gen / Aseprite refinement
  -> sprite-sheet.png + engine manifest
```

Run the verification demo from the repository root:

```bash
./Tools/VoxelTurnaround/run_demo.sh
```
