# 반려 기록 (전 화면 공통 · append-only)

> 스킬 `game-ui-from-concept` 4단 산출. 화면별로 쪼개지 않는다.
> **같은 반려가 두 번 나오면 그건 제약으로 올린다.** 뒤로 갈수록 라운드가 줄어드는 유일한 방법.

## 형식

```
### YYYY-MM-DD · <화면> · 라운드 N
- 위반: <제약 ID 또는 불변식>
- 실제: <측정값 또는 관찰>
- 기대: <사양 값>
- 처리: 3단 재위탁 / 사양 수정 후 재시작 / 작가 판정 대기
- 승격 후보: yes|no  (두 번째 발생 시 yes)
```

## 승격된 제약

- **[후보 · 1회] 제약이 의도보다 넓은지 검사한다** — 2단 완료 판정에 추가 검토. 근거 = 2026-09-01 로비 라운드 1. 한 번 더 나오면 확정 승격
