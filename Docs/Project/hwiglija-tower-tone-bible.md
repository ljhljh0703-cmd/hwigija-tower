# hwigi-tower — Tone Bible

> 본 파일은 게임의 **목소리**(voice) 단일 참조점.
> 모든 UI 텍스트, NPC 대사, 마케팅 카피, 외주 브리프 톤이 본 파일과 정합해야 한다.
> 디자인 결정은 [[hwiglija-tower-gdd]] §0.6 PILLARS 와, 텍스트는 본 파일과 — 둘 다 일치해야 잠금.

---

## 0. 한 단어로

> **체념의 따뜻함** — *cold dignity, warm goodbye*.

겨울이지만 잔인하지 않다. 끝이지만 분노하지 않는다. *μάταιος* — 무가치하지만 미워하지 않는다.

## 1. 4개의 음역 (Voice Registers)

| 음역 | 화자/맥락 | 문체 |
|------|----------|------|
| **A. NPC 마타이오스** | 휴식·회상·전투 중 발화 | 1-2문장. 단답·여백·기시감. 한자어 + 일상어 혼용. 회차가 깊을수록 단답·반복·글리치. |
| **B. 시스템 텍스트** | UI, 인카운터 설명, 능력 툴팁 | 무미건조 + 한 단어의 시. 구두점 절제. |
| **C. 메모리 파편** | NPC 회상 노출 (5개) | 시적·단편적·시점 흐림. 누구의 기억인지 *명시하지 않는다*. |
| **D. 메타 텍스트** | "탑이 당신을 알아본다" 류 (인카운터 25 중 2개) | 4th wall 깸. 2인칭 ("당신"). 짧고 차갑게. |

## 2. 음역별 샘플 (canonical — Codex/외주가 인용 가능)

### 2.1 A — NPC 마타이오스

**S0 첫 만남 (1회차)**
> "당신도 무언가를 잃었나 봐. ……동행해도 되겠어?"

**S1 인지 (2-3회차, 1번 보스 격파 후)**
> "이 방… 처음이 아니지?"
> "기시감이라기엔 너무 또렷한데."

**S2 동행 (4-7회차, 회상 명확화)**
> "당신과 이렇게 걷는 게, 왜 이렇게 익숙할까."
> "내가 잃은 게 뭔지, 조금씩 떠올라."

**S3 균열 (8-10회차)**
> "잠깐 — 우리 어디까지 왔지?"
> "당신 이름이… 뭐였더라."
> "이 층, 분명 지나왔는데."

**S4 붕괴 (11-13회차)**
> "당신 누구야"
> "또"
> "기억이… 흩어"

**S5 안식 (엔딩 A)**
> "괜찮아. 잊어도 괜찮아."
> "고마웠어. 정말."

**S5 동행 (엔딩 B, 다음 루프 직전)**
> "다시 가자. 한 번만 더."
> *(다음 회차 1층에서 그는 다시 첫 만남으로 돌아와 있다.)*

### 2.2 B — 시스템 텍스트

**능력 툴팁** (담백):
> **광폭** — 검 3장 시너지. 공격 시 1추가타.

**인카운터 노드 라벨**:
> 휴식 / 전투 / 상점 / 잔재

**사망 화면**:
> 회귀.

**층 진입**:
> *3층 — 잔해의 정원*

### 2.3 C — 메모리 파편 (5개, S2-S4 분할 노출)

> *방향성 샘플 — 실제 5개 텍스트는 OQ-006 에서 작가 직접 작성*

**파편 1** (S2 초기):
> 누군가의 손이 내 손을 잡았다. 따뜻했다. 누구였는지 기억나지 않는다.

**파편 5** (S4 붕괴 직전):
> 잊는 게 무서운 게 아니야. 잊었다는 사실조차 잊는 게 무서워.

### 2.4 D — 메타 텍스트

> 탑이 당신을 알아본다.

> 같은 방. 같은 선택. 다시.

## 3. 금지선 (Forbidden Patterns)

| ❌ 금지 | 이유 |
|--------|------|
| 느낌표 남발 ("!", "!!") | 차가운 톤 깨짐 |
| 이모티콘·이모지 | 캐주얼 표면이 서사 무게를 압도 |
| 라이트노벨식 호칭 ("주인님", "당신♡") | 톤 충돌 |
| "AI 가 만든 대사예요!" 류 마케팅 | Anti-Pillar — LLM 자랑 X |
| NPC 가 자기 이름의 의미(μάταιος = 무가치) 를 *직접 설명* | 결말이 미리 누설됨 |
| 망각을 "아름답다"고만 그리기 | P1 위배 — 비극과 해방의 *양가성* 유지 |
| 도덕적 선택의 결과를 점수로만 표시 | P5 위배 — 즉시 발화 변화로 보여야 |

## 5. 외주 브리프 (구두 전달용 핵심 키워드)
