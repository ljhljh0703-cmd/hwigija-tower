## Runtime Wiring
- GeneralEncounter and MoralChoice assets are added to `SO_Node_Event` candidate pool.
- Existing Shop, Rest, and CombatGate node wiring is preserved because sheet data lacks purchase/rest/combat handoff effects.
- Current `EncounterSelector` does not filter by floor; floor-specific event selection requires a small runtime change or floor-specific node pools.
