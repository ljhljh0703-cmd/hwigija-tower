## Game Design Feedback
### What works
- The required vertical-slice structure exists: Lobby first scene, new game, route map, event, combat, rest input, shop, boss, save/continue, and ending choice.
- The art direction is coherent when background art is bound: dark tower interiors, shop staging, enemy image, and Mataios portrait support P1's recovery/collapse mood.
- Shop-before-boss is a good structural rule. It gives the run a readable "prepare, then commit" beat.

### What does not work yet
- The game does not yet sell "I am choosing a path" strongly enough. Node labels alone are not enough; the player needs tradeoffs.
- Combat is legible as a UI loop, but not yet as a tactical loop. Without enemy intent and skill preview, Attack is likely to become the default.
- Mataios is present visually, but her agency is not visible enough outside Rest. The game needs more immediate NPC response to choices to satisfy P5.

### What would make it more fun
- Give every node preview one hook: "safe gold", "memory risk", "hard fight / high reward", "Mataios uneasy". This makes the map a decision instead of a menu.
- Make each combat round ask a small question: "take damage to finish now, defend to survive, use skill for setup."
- After each node, show one compact result strip: gain/loss + Mataios response + next unlock.

### What would make Mataios feel more alive
- Add 1-line contextual barks after event/combat/shop outcomes. Keep them writer-approved or template-keyed; do not generate final lore ad hoc.
- Reflect player Rest input back in a small visible memory chip: "방금 한 말: ..." then later reuse it.
- Let her emotional state affect the next combat modifier in a visible way: "동요: 방어 효율 -1" or "안정: 첫 피해 -1".

### What would improve node-map decision making
- Draw visible path connections and lock unreachable nodes after selection.
- Put reward/risk badges directly on selectable nodes.
- Show boss convergence more explicitly: all paths should visually point upward into boss/shop.

### What would improve combat
- Add enemy intent and next-action forecast.
- Add action tooltips/previews: Attack damage, Defend mitigation, Skill condition/effect.
- Add stronger hit/defend feedback and post-round text that explains why HP changed.

### What would improve events
- Ensure every event choice has distinct risk/reward and an immediate emotional reaction from Mataios.
- Keep probability/reward visible, but phrase it in-world where possible.
- Avoid generic `Choice 1/2/3` or raw placeholder labels in any demo-facing mode.
